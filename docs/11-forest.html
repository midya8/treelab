      A lower bound for the unseen frontier
      Intersect split constraints across all members. Propagate branches forced by the current box. Project the source onto that box to get its exact weighted-L1 lower bound. Remaining subtree means give a conservative ensemble-output range. Incompatible boxes and impossible output bands are pruned. A best-first queue expands the lowest-cost frontier box next.
      A feasible full-ensemble witness supplies an upper bound. Search stops with an optimum when no remaining box can improve that cost; an empty frontier without a witness proves infeasibility. Otherwise a reached budget returns the minimum frontier cost as a lower bound. No independent-member maxima are added together.
      The search can grow exponentially. Even with verified one-axis seeds, 4,096 all-feature expansions do not complete these fixed real-data requests. Restricting to alcohol can finish, but its optimum is only for that constrained domain. This is an explicit limit, not an omitted failure.
