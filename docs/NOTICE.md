# Attribution and scope

Explorer code: MIT, see ../LICENSE. The browser report is an exact export of
TreeLab's frozen one-feature response report. Data and derived outputs:
Cortez et al. (2009), UCI Wine Quality, DOI 10.24432/C56S3T, CC BY 4.0.
The original data, hashes and provenance are in ../treelab/data/LICENSE.md.
No source endorsement.

CART, bootstrap aggregation and ICE-style individual model response analysis
are established methods, not claimed inventions. See ../SWEEPS.md and
../EXPLORER.md for sources, finite-domain semantics and limitations.

No model fitting, arbitrary-input inference, analytics, accounts, model API,
remote data service or upload occurs in the explorer. The browser reads only
bundled public results. Holding one feature fixed against its complement can
create impossible combinations. Ranges are attainable model outputs on one
specified slice, not uncertainty, causality, plausible-wine guarantees or
joint-feature robustness bounds.
