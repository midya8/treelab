Every feasible target leaf
One closest point per feasible leaf, ranked by exact rational cost. This is an exhaustive single-tree leaf search, not a random perturbation or arbitrary epsilon. The listed boxes have inclusive binary64 endpoints; a strict right threshold is replaced by its next representable successor.
    

    What the optimum means
    Intersect each leaf path with the supplied closed feature bounds. Lock immutable features to the source. Project the input onto each remaining box and compare exact weighted L1 costs. A separable positive-weight L1 objective makes this coordinate-wise projection globally optimal within its leaf. Enumerating every target leaf gives the global result under these constraints.
    Finite binary64 inputs only. Exact rational comparison refers to the stored input and weight values, not ideal decimal arithmetic. No causal structure, data-density check, discrete chemistry constraints, intervention cost model or ensemble search is included. No new model is fit and no test-accuracy claim is made.
    Established closest-leaf counterfactual geometry, not a new algorithm.
